Tailscale 連携 (= 外出先から自宅 daemon へアクセス)

Tailscale が install + login 済なら、 自宅 PC の OpenMoney web UI に外出先から ポート開放なしでアクセスできます。 各デバイスは公開鍵で認証され、 トラフィックは E2E 暗号化 (= WireGuard ベース)。

 Tailscale を install / login 直後はこのボタンで再検出してください。

アプリユーザ管理 (= 連携 Android 端末 + PC)

この PC の uid に紐付いている Android 端末 + PC endpoint 一覧。 旧端末・不要 entry はここで解除できます (= 旧 user 宛の OTP push が届かなくなる)。
自 PC 自身を解除するには ./goodbye.sh を使ってください (= ローカルファイル削除も含む)。

再ペアリング

Android アプリで発行した 8 桁コードを入力してください。
トークンが失効した場合や端末を変更した場合に使用します。

サービス (プラグイン)

plugins/<name>/ に置いた各プラグインが選択肢として登録されます。 トグルで daemon の対象から除外可能。env キーは保存時に解錠中なら即暗号化、 未解錠なら平文で保存し後でまとめて暗号化できます。
新しいプラグイン追加後は uv run python -m src.plugins_build + daemon 再起動。

▶ .env キー暗号化状態 (全件)

🔒 = 暗号化済 (AES-256-GCM + scrypt) / 🔓 = 平文 / —— = 値が空。 上のサービスカードに含まれない補助キーもここに出ます。

▶ OS Keychain 自動解錠

OS Keychain (macOS は Keychain Services) に master password を保存しておくと、 daemon 再起動のたびに /login から打ち直す必要がなくなります。 Keychain は OS のログインアカウントで保護されるので、UI 暗号と同等以上の セキュリティで保管されます。

▶ マスターパスワード変更

.env の暗号化済値を全て新パスワードで再暗号化します。 OS Keychain に master を保存している場合は同時に上書き更新されます。 解錠中のみ実行可能。
