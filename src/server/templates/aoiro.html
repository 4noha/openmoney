概観 Phase 1

青色申告 (個人事業主) で必要な帳簿・決算書・申告書類を一括で作成する独立サブシステム。 transactions テーブルからは read-only で参照し、自前の aoiro_* テーブル群に書き出します (支出分類ロジックには影響しません)。 出力は e-Tax を最優先目標とします。

▶ 📥 インポート (過去年度の取込)

過去年度のデータから snapshot を作成。通常は (1) を使用。 (2) は (1) で取込済のデータを再利用するための補助手段。

(1) 過去の納税/ から PDF + CSV を一括読込 推奨

過去の納税/<年度>/ の CSV (帳簿) + PDF (申告書等送信票) から 仕訳・PL・BS・申告書 B 第一表 (給与・税額・源泉) ・所得控除明細 (社保・生保・医療費等) を一括取込して snapshot 作成。

(2) 取込済 tax_* から snapshot 作成 補助

既に tax_journal / tax_pl / tax_bs に取込済のデータを aoiro snapshot 形式に変換します。(1) で取込済なら不要。

transactions の category / tag / bank / 金額 / keyword を判定して 借方科目を決定。credit_account 空 なら下の bank → 科目マップで貸方を解決します。 priority が小さいルールが優先。

損益計算書 (PL) Phase 2 ✓

収益 = credit-debit / 費用 = debit-credit を仕訳から集計。 売上原価 = 期首棚卸 (5002) + 仕入 (5001) − 期末棚卸 (5003)。

📥 月次 CSV 📥 前年比 CSV
年度を選んで表示

貸借対照表 (BS) Phase 2 ✓

期首残高 + 当期仕訳 → 期末残高。資産 = 負債 + 資本 + 当期純利益 の検算。

年度を選んで表示

月次 BS 推移 (科目別 月末残高)

資産 = 借方残 (正)、負債/資本 = 貸方残 (正) で表示。closing 仕訳がある年度は 12 月に 3001 元入金へ集約されます。

「月次 BS 表示」をクリック

月次 普通預金 推移 vs 実 MUFG 残高

帳簿の 1002 普通預金 期末 と 実際の MUFG 残高の月末を比較。誤差が膨らむ月 = 反映されていない入出金がある。

「月次比較を更新」をクリック

期首残高 (BS の前期繰越)

資産 = debit_balance / 負債・資本 = credit_balance に入れる。前年の BS から手入力 or 自動推定。

accountnametype debit credit

家事按分 Phase 4 ✓

勘定科目ごとに業務按分率 (0〜100%) を設定。仕訳エンジンが rebuild 時に 経費仕訳 (按分後額) + 事業主貸 3002 への振替仕訳 (残額) の 2 本を生成し、 BS の元入金/事業主貸を正しく動かします。設定後は仕訳の rebuild が必要です。

優先順位: rule.business_ratio (≠100) → account 単位 (ここで設定) → 100%。

scope科目 業務% note

所得控除 Phase 6 ✓

申告書 B 第一表「所得から差し引かれる金額」に集計。種類別 (医療費 / 社保 / iDeCo / 生命保険 / 地震保険 / 寄附金 / 扶養 等) に金額・支払先・証憑を記録。

tag=medical の transactions から医療費控除を選択

チェックを入れた取引の合計を 1 件の医療費控除として登録できます。

tag=insurance の transactions から保険料控除を選択

支払先・契約区分が複数あるので、生命保険 / 地震保険 / 損害保険 (経費側) を分けて登録できます。 生保・地震保険は所得控除、火災/自動車保険などは事業経費 (PL) になるので注意。

消費税申告 (インボイス) Phase 6.5 ✓

インボイス管理 (/invoices ページ) の tax_expense_items + invoice_vendors から、年度別の課税仕入を集計。 適格請求書発行事業者番号 (T+13桁) の有無で 100% 控除 / 経過措置に振り分け。 確定申告で消費税申告 (簡易課税 or 一般課税) を行う際の参考。

「サマリ更新」をクリック

出力 + 申告書 B 集計 Phase 7 ✓

申告書 B 第一表の所得・控除を年度集計 → snapshot freeze して提出データを凍結 + CSV エクスポート。 e-Tax XTX/XML 直送と PDF 値埋は次フェーズ。税額計算は Phase 8。

📋 e-Tax 確定申告書等作成コーナー — 入力値表 Phase 8

e-Tax の Web 入力フィールドに 手動コピー&ペースト するための値表。 各項目に「📋 コピー」 ボタンが付いており、e-Tax の対応欄をクリックして貼り付けます。 snapshot ロック済年度はその凍結値、それ以外は live 計算値。

「読込/更新」 をクリック

申告 snapshot 管理 + CSV 出力

snapshot を保存すると、その時点の PL/BS/控除/不動産/申告書 B が JSON として aoiro_declaration_runs に凍結されます。 lock 状態のものは変更不可 (税務調査時のエビデンス保全用)。 通常はヘッダの「📅 表示年度」 と「🔒/✏ unlock/lock」 ボタンで操作してください。
